## 게임 구성

### 자원

**골드**
- 기본적인 자원으로 카드 구매 또는 벽 생성 에 사용됩니다.
- 골드는 전투 라운드 시작시 0으로 초기화 됩니다.
**마나**
- 상점 카드 구입 과 카드중 일부 카드는 마나가 소비됩니다.
- 준비라운드 시작시 마나2가 제공됩니다.

**샤드**
- 해당 게임에서 얻을수 있는 특수 재화 입니다.
- 전투 라운드가 지나도 사라지지 않는 재화이며 샤드1개로 골드로 바꿀수있고 샤드2개로 마나로 바꿀수 있습니다.

### 준비 라운드
**준비 라운드 시작**
- 플레이어는 덱에서 카드 5장을 드로우 합니다.
- 준비 라운드 에서 만 상점에서 카드 를 구매 할 수 있습니다.
- 매 라운드 시작시 묘지로 간 카드를 덱에 합칩니다.

**플레이어 행동**
- 플레이어는 타일을 클릭하여 자원을 소모해 벽을 생성 할 수 있고 경로에 벽이 지어지면 경로를 재계산을 해서 새로운 경로가 표시됩니다.<br>
<sup>(지나갈 수 없는 경로를 만들면 진행이 불가능합니다.)</sup><br>
<sup>(벽 설치 및 제거는 준비 라운드 에서만 가능합니다.)</sup><br>
<sup>(벽을 지은 라운드에는 무료로 철거 할 수 있습니다.)</sup>
- 플레이어는 벽 타일 위에 유닛카드를 배치 할 수 있습니다.<br>
<sup>(카드 종류중 유닛 카드만 배치 할 수 있습니다.)</sup>

**상점**
- 게임 시작시 기본적으로 상점에 매물 6종류가 배치되며 플레이어는 마나1을 소비해 상점의 카드를 구매 할 수 있습니다.
- 각 매물에는 수량이 존재 하며 모든 수량을 다 구매할 시 품절이 됩니다.
- 품절이된 매물은 재등장 하지 않으며 일부 카드의 효과나 보스 보상으로 상점리롤을 이용해 매물교체를 할 수 있습니다.<br>
<sup>(교체된 매물은 첫등장시 수량 6개로 등장합니다.)</sup>

**카드 종류**
- 유닛,효과,자원,마법

**유닛 카드**
- 유닛 카드는 벽 타일에 배치 할 수 있으며 사거리 내에 적을 자동으로 공격합니다.
- 유닛 카드는 사용할 수 없습니다.<br>
<sup>(예외로 다중 타입인 유닛카드는 사용할 수 있습니다.)</sup>

**효과 카드**
- 카드중 특별한 효과를 사용 할 수 있는 카드입니다.<br>
<sup>(드로우를 하거나 카드를 파괴 후 이득을 주는 효과를 가지고 있습니다.)</sup><br>
<sup>(카드를 파괴 하면 덱 및 유닛카드 일경우 배치한 유닛까지 영구히 제거됩니다.)</sup>

**자원 카드**
- 사용을 하면 자원을 주는 카드 입니다.<br>
<sup>(기본적인 자원은 전투라운드시 사라지지만 *샤드* 는 사라지지 않습니다.)</sup>

**마법 카드**
- 마법 카드는 주로 효과 카드의 효과로 인해 얻을 수 있습니다.
- 마법 카드는 준비 라운드와 전투 라운드에 사용 할 수 있는 카드로 나눠집니다.
- 준비 라운드에서 사용할 수 있는 카드는 주로 자원을 얻거나 드로우등 이득을 주는 효과를 지니고있습니다.
- 전투 라운드에서 사용할 수 있는 카드는 주로 유닛을 강화시키거나 적에게 피해나 상태이상을 주는 효과를 지니고 있습니다.

### 전투 라운드
**진행 방식**
- 승리 조건은 따로 없으며, 무한 라운드로 진행됩니다.
- 적이 끝지점에 도달하면 체력이 1 감소합니다.
- 보스가 끝지점에 도달하면 체력이 10 감소합니다.
- 일부 효과 카드로 체력을 회복할 수 있습니다.
- 체력이 0이 되면 패배하며, 게임 종료 시 최종 점수가 표시됩니다.

**적**
- 스폰 지점으로 부터 끝지점까지 경로를 따라 이동합니다.<br>
<sup>(적은 유닛을 공격하지 않습니다.)</sup>

**보스**
- 5라운드 마다 보스가 출현하며 잡으면 *샤드* 를 줍니다
- 보스를 처치한 라운드 종료시 보스처치 보상을 획득하게 됩니다.

### 점수 시스템
- 일반 몹 처치 시 10점, 보스 처치 시 100점을 획득합니다.
- 게임 종료(패배) 시 누적 점수가 결과 화면에 표시됩니다.

## 기술적 특징 / 아키텍처

### 전체 구조: 역할 기반 싱글톤 매니저 분리
게임 로직을 하나의 클래스에 몰아넣지 않고, 책임 단위로 매니저를 분리해 구현했습니다.

| 매니저 | 역할 |
| --- | --- |
| `CardGameManager` | 덱/손패/묘지 순환, 카드 획득·드로우·파괴 |
| `DefenceGameManager` | 라운드 진행, 페이즈(준비/전투) 전환, 웨이브 스폰, 벽 배치 |
| `MagicManager` | 마법 카드 전용 관리 (덱 순환에서 분리된 별도 슬롯) |
| `StoreManager` | 상점 매물/재고/리롤 |
| `UpgradeManager` | 공격력 버프 (영구/이번 라운드/시간제한) 합산 |
| `ScoreManager` | 점수 집계, Firebase 연동 최고 기록 저장 |
| `SoundManager` | SFX/BGM 재생 및 볼륨 믹싱 |
| `TutorialManager` | 튜토리얼 플로우 제어 |

각 매니저는 `Instance` 싱글톤으로 접근하고, 서로 직접 참조하기보다 **C# 이벤트(`Action`/`event`)로 통신**하도록 설계했습니다.
예: `CardGameManager.UnitSlotClicked` 이벤트를 `DefenceGameManager`가 구독해 실제 유닛 배치를 처리 — 카드 시스템과 필드 배치 로직을 분리했습니다.

### 데이터 테이블 기반 카드/유닛 설계
카드·유닛·스테이지 데이터를 코드에 하드코딩하지 않고 `DataTableManager`를 통해
외부 테이블(CSV)에서 로드하도록 설계했습니다. 효과/자원 카드는 테이블의 Behavior
컬럼에 적힌 클래스명을 런타임에 리플렉션(`Type.GetType`)으로 동적으로 부착해,
같은 프리팹 하나로 다양한 카드 효과를 처리할 수 있도록 했습니다.

### 점수 기록
- 로컬 최고기록을 `PlayerPrefs`로 저장해 매판마다 최고기록을 노릴수 있게 했습니다.

### 무한 라운드 난이도 스케일링
- 스테이지 수가 늘어날수록 몬스터의 수 와 체력을 늘리는 방식으로 무한 라운드 설계
- 일정 스테이지 이후로는 스테이지 패턴을 순환

## 문제1 난이도에 따른 벽 개수 증가로 인해 경로 차단 문제

**문제**
- 난이도에 따라 벽갯수가 증가하는 방식인데 게임시작이 완전 히 경로가 차단된 필드가 생성이됨.

**해결**
- 랜덤 벽생성 이후 경로 계산 후 경로가 차단되어있으면 벽 전부 제거후 다시 생성 반복

**결과**
- 높은 난이도 에서도 경로가 최소 한개 보장된 상태로 시작하게 됨.

## 문제2 카드의 다중타입 배치및사용 처리
**문제**
- 기본적으로 카드 타입을 나눠 다른 동작으로 사용합니다.
- 다중 타입으로 일부카드는 유닛 카드(사용불가능 한) 이면서 효과 카드(사용 가능한) 다중 타입의 카드가 존재할 수 있습니다.
- 단순 열거형 으로 하나만 관리해서 유닛이면서 효과를 동시 발동 가능한 카드 표현이 불가능합니다.

**해결**
- 카드의 타입과 행동 로직 분리
- 유닛 카드여도 효과가 사용가능한 카드면 사용할 수 있게 적용

**결과**
새로운 다중 타입 카드를 추가할 때 코드 분기를 늘리지 않고, 데이터 테이블의 UseAble 값만 설정하면 되도록 확장성을 확보했습니다.

## 문제3 배치된 유닛과 카드의 동기화
**문제**
- 카드 파괴하는 효과가 발동해도 카드만 파괴되고 이미 배치된 유닛은 제거가 안됩니다.
- 필드의 유닛과 덱에 카드가 각각 다른 개체로 존재

**해결**
- 유닛과 카드에 Id를 부여 후 카드가 파괴되어도 이미 배치되어있는 유닛에 id가 같으면 파괴할수있도록 적용<br>
<sup>(만약 배치안되어있고 패널에 유닛이 따로 존재하면 패널 유닛도 파괴)</sup>

**결과**
- 카드 효과로 손패의 카드를 파괴해도 필드에 배치된 유닛이 사라진걸 확인할 수 있습니다.
